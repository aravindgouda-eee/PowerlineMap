# ⚡ PowerlineMap – Power Transmission from Srisailam to MGIT

An interactive power transmission map built using **Python, Streamlit, FastAPI, and Folium** to visualize the transmission route from Srisailam Power Plant to MGIT using geographical coordinates and location images.

## 📌 Project Overview

PowerlineMap provides a geographical visualization of the power transmission path from Srisailam Power Plant to Mahatma Gandhi Institute of Technology (MGIT). It displays locations and transmission lines on an interactive map using latitude and longitude coordinates.

The application combines a Streamlit frontend with a FastAPI backend to retrieve location and transmission-line data and present it visually.

## ✨ Key Features

- **Interactive Map:** Displays power-related locations and transmission lines.
- **Geographical Coordinates:** Uses latitude and longitude to identify locations.
- **Location Images:** Displays relevant images for selected locations.
- **Transmission Route Visualization:** Illustrates the route from Srisailam Power Plant to MGIT.
- **Web-Based Access:** Allows users to view the map through a browser.

## 🏗️ How It Works

1. The FastAPI backend provides location and transmission-line data.
2. The Streamlit application retrieves data from the backend.
3. Folium renders the map, location markers, and transmission lines.
4. Selected locations display relevant information and images.
5. The application is deployed online for browser access.

## 🎯 Project Objective

To demonstrate power transmission route visualization by combining electrical engineering concepts with web development, API integration, and interactive mapping.
